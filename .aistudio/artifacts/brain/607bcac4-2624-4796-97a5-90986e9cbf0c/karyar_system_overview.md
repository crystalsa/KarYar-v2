# راهنمای جامع معماری و فنی سامانه کار‌یار (KarYar)

سامانه **KarYar** یک نرم‌افزار حرفه‌ای، آفلاین و محلی مدیریت کارگران، حضور و غیاب، کارکرد روزانه و حسابداری کارگاهی مبتنی بر اندروید مدرن، Jetpack Compose، دیتابیس Room و معماری Clean Architecture است.

---

## ۱. ویژگی‌های کلیدی سامانه
- **پایگاه داده محلی و امن (Offline-First):** ذخیره‌سازی کامل اطلاعات در دیتابیس محلی SQLite با Room بدون نیاز به اینترنت.
- **تفکیک قطعی روزهای تقویمی کارگاه و نفر-روز:** محاسبه مجزا بین «تعداد روزهایی که کارگاه دایر بوده است» و «مجموع کارکرد پرسنل (شیفت/نفر-روز)».
- **فرمت‌دهی هوشمند بدون کلمات مخفف:**
  - حذف کلیه حروف اختصاری نامفهوم نظیر «ر» و «س» و نگارش کامل کلمات (روز، ساعت، تومان).
  - عدم نمایش ساعات غیرضروری برای کارگران تمام‌روز (صرفاً نمایش `۲ روز`).
  - تفکیک شفاف و کامل کارکرد چندحالته برای کارگران با وضعیت‌های مختلط به صورت `(۱ روز: تمام‌روز) (۲ روز: نصف‌روز) (۱۶ ساعت: ساعتی)`.
- **خروجی رسمی افقی (Landscape) و کاملاً RTL در PDF و Excel:**
  - طراحی گزارش رسمی PDF در ابعاد افقی A4 Landscape ($842 \times 595$).
  - چینش ستون‌ها، کارت‌های مالی و خطوط امضا به صورت کاملاً راست‌به‌چپ.
  - خروجی اکسل/CSV ایمن با انکودینگ UTF-8 BOM بدون خطای فونت فارسی.

## ۲. معماری نرم‌افزار و لایه‌بندی
```
com.karyar.app
├── data
│   ├── local (دیتابیس Room، DAOها و Entityها)
│   └── repository (مدیریت تراکنش‌ها و دسترسی منسجم به داده‌ها)
├── domain
│   └── model (مدل‌های محاسباتی، عملکرد پرسنل و خلاصه داشبورد)
├── ui
│   ├── screens (داشبورد، کارگران، حضور و غیاب، پوشه‌ها و گزارشات)
│   ├── components (المان‌های رابط کاربری متریال ۳)
│   └── theme (رنگ‌بندی، تایپوگرافی و شیپ‌ها)
└── util
    ├── WageCalculator (موتور محاسبه حقوق و دستمزد)
    ├── JalaliCalendar (محاسبات تقویم خورشیدی)
    ├── Formatters (تبدیل به ارقام فارسی و فرمت پولی)
    ├── PdfExportUtil (رندر و خروجی اسناد PDF افقی)
    └── ExcelExportUtil (صادرکننده فایل‌های اکسل و CSV)
```

## ۳. چرخه CI/CD و بیلد خودکار در GitHub Actions
- **اسکریپت گیت‌هاب اکشنز:** مسیر `.github/workflows/build-release.yml`
- **تست‌های خودکار:** اجرای ۵۲ تست واحد local JVM پیش از هر بیلد.
- **تولید APK:** ایجاد و بسته‌بندی خودکار فایل `WorkerManager-App.apk` به عنوان Artifact در تب Actions گیت‌هاب.
